# Commit message style

- Keep it short and to the point — a single summary line is usually enough; add a body only if a key change genuinely needs one more short sentence of context.
- State only the key change(s) made, not implementation detail, rationale for minor choices, or a restatement of the diff.
- No emojis, anywhere in the message.
- Keep the subject line under ~70 characters, written in the imperative mood (e.g. "Fix", "Add", "Move"), no trailing period.
